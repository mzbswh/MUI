# MUI 最终设计目标

> 目标环境：Unity 2022.3.62f3、uGUI、Unity Package Manager 标准包。TMP 与 Input System 是按需安装的适配依赖。

## 1. 产品目标与结构

MUI 为 Unity 游戏提供页面、数据绑定、导航、输入控制和资源清理的完整 uGUI 框架。普通页面由 ViewModel、生成绑定、View/Element 和 Route 组成；Presenter 只在页面需要协调业务流程时使用。

- UIHost 组装 Navigator、Provider、主线程与逐帧驱动。每个宿主独立持有导航、页面和焦点状态；共享 EventSystem 时通过统一输入仲裁确定输入所属宿主，不承诺共享输入下完全独立。
- Core 提供不依赖 Unity 的状态、命令、绑定契约、LifetimeScope、输入门控和错误出口。Resources 提供资源及视图持有权契约。Navigation 管理页面实例、状态、结果和策略。uGUI 负责控件与原生事件，Editor 不进入 Runtime。
- 项目提供业务服务、数据仓库、DI、资源加载后端和共享缓存。MUI 通过明确接口与这些能力对接。
- 实现以页面开发所需能力为边界：复用统一作用域、代际与资源凭证，不为每种操作建立独立事务系统；只检查框架入口可识别的直接自等待，不构建通用 Task 依赖图。资源失败由适配器提供安全重试入口，框架保留责任记录，不实现通用恢复调度器。多宿主仲裁按需启用，单宿主使用默认配置；诊断按需采集且有界，不长期保存全部操作历史。
- 页面导航、准备、绑定生命周期、Provider 获取、子视图、列表、预加载和清理使用统一的异步契约，不提供纯同步宿主、Provider 或页面生命周期的第二套 API。本地数据、常驻 Prefab 和立即完成的业务逻辑可在同一帧完成，不人为等待下一帧；Unity 主线程不通过阻塞 Task 取得结果。
- Provider 对外只保留异步获取与预加载入口；同步后端可通过委托适配器接入，同步完成后直接返回已完成结果，不使用 Task.Run、强制 Yield 或阻塞等待来包装。同步创建函数可作为适配器内部实现，但不要求每个 Provider 同时实现 Create/CreateAsync，也不增加同步 Navigator 分支或 Route 同步能力标志。Provider 立即完成不代表整个页面打开立即完成，页面准备、守卫、队列与布局仍遵守各自契约。
- 异步返回类型默认优先 Task 的简单消费语义；Provider 等高频、单次消费入口只有在分配测量证明收益后采用 ValueTask。采用时由框架只消费一次，BeginOpen、页面结果及清理等允许多个观察者的完成状态使用可重复等待的 Task，不共享原始 ValueTask。若未来确有必须立即取得已就绪对象的需求，单独评估无等待、未命中不启动加载的 TryAcquireReady 能力，本次不实现通用同步 Provider API。

## 2. 数据、绑定与控件

- ViewModel 支持属性与集合通知。ObservableProperty、OnChanged、计算属性的显式依赖通知、ObservableList 的版本与稳定键、增删改移、重置和事务批次通知形成一致的数据契约。稳定键在同一来源内唯一；重复键明确报错。
- 命令使用统一的异步执行契约，接受可立即完成的同步业务委托，并提供可执行状态、并发策略、取消和结果。框架从 Unity 同步事件回调派发命令并观察完成与异常。控件事件携带来源激活与绑定代际，执行前重新检查代际、输入资格和可执行状态；失效事件不执行，门控关闭期间的事件不积压到恢复后执行。
- InputGate 只控制新输入准入，临时关门不自动取消已接纳命令，也不使其结果失效。页面关闭、换绑或条目复用后，旧结果不得附着到新的 UI 上；在途命令按命令策略与所属作用域取消。必须继续完成的业务工作由项目服务持有，业务完成与 UI 结果附着分别处理。
- 绑定支持单向、双向和一次性模式，转换器、继承及嵌套 ViewModel。生成器产出 BindingContext、跨程序集元数据、显式 View 注册和 Route 接线；不支持的声明或泛型组合在编译期定位。UPM 包内的 Analyzer 与运行时代码版本一致。
- 双向绑定默认由模型初始化控件；模型到控件的更新不再次触发业务输入。输入框支持逐次编辑和结束编辑两种提交时机；转换失败保留原模型值并提供可绑定的校验状态，不作为框架异常。嵌套 ViewModel 替换时解除旧订阅并切换代际；变为 null 时写入声明的回退值或目标类型默认值，禁用该路径的反向写入。
- 初次绑定、换绑、解绑有明确所有权；旧订阅和半绑定控件必须清理。共享 ViewModel 默认由项目持有，只在明确移交所有权时由页面释放。换绑的异步准备不得修改当前控件、订阅和业务状态；准备失败保留原绑定。提交在主线程短步骤内切换订阅、绑定代际和初始值，不等待外部任务；任意用户 setter 或回调的副作用不承诺回滚。提交异常立即撤销相关视图输入，清理新旧绑定并按故障关闭或移除相关视图，页面按故障关闭时绕过守卫且不进入缓存。
- 提供通用的可见性、局部内容激活、可交互、透明度与射线阻挡绑定；隐藏与透明不自动等于关闭、释放或允许输入，输入仍由页面资格统一约束。页面及子视图的生命周期由 ViewInstance 驱动，局部内容显隐不得替代导航关闭或子视图停用。
- 项目可通过公开契约登记自定义 Element 属性、事件、转换器和第三方控件适配；生成器检查声明并生成接线。自定义适配沿用绑定代际、输入资格、错误和释放契约，不要求修改框架源码。
- Element 包装已有 Unity 组件，不继承并替换原生控件实现；未绑定的视觉属性保留 Prefab 配置，已绑定属性由绑定契约驱动。Text、InputField、Dropdown 提供不依赖 TMP 的公共内容、值及事件契约，Legacy/TMP 适配实现同一契约，后端专属排版或输入属性仍由具体适配提供。目标按声明标识及兼容契约解析，缺失或多义时明确报错，不在运行时自动添加后端组件；切换后端不要求修改仅使用公共属性的 ViewModel。
- 自定义 Element 通过 CreateProperty、Track 和 TrackCleanup 等统一注册入口接入已有 LifetimeScope，不另建释放系统。监听、命令和持有凭证在初始化失败及正常释放时按明确顺序清理；有依赖的回调按逆序释放，失败仍沿统一责任记录处理。View 的 Element 扫描在子 View 或声明的容器边界停止，父级持有容器，子级独占内部控件；编辑器与运行时使用相同边界，禁止重复初始化和释放。
- uGUI Element 覆盖 Text、Image、RawImage、Graphic、Button、InputField、Toggle、Slider、Dropdown、ScrollRect、Scrollbar、AspectRatio、LayoutSize、Mask 和 RectMask，提供对应原生属性、输入配置、文字排版和图像填充绑定。
- Sprite、Texture、Material 和 uGUI Font 支持资源键绑定。显示位置管理本次资源凭证，处理异步换键、立即完成的本地资源、失败重试、赋值异常和迟到凭证归还。
- 资源槽分别记录请求键、当前显示键/对象及加载状态。换键默认保留旧画面；取得并验证候选、确认代际有效、成功赋值后才接管候选凭证并归还旧凭证。加载失败保留旧显示与凭证，暴露请求键的失败状态供显式重试，不偷偷回写业务请求键；旧凭证归还失败保留独立清理责任，不撤销已成功切换的新资源。直接赋值对象或清空键使在途请求失效，并在显示替换或清空后归还旧凭证；直接对象默认借用。赋值异常须清除或恢复可确认的显示引用，无法确认时禁用相关显示并保留必要凭证进入故障清理，不盲目归还仍可能被使用的资源。
- 安装 TMP 的工程可使用 TMP Text、InputField、Dropdown 的绑定、排版属性及直接字体对象绑定；该适配独立编译。

## 3. 导航、状态与结果

- Route 描述页面配方，ViewHandle 唯一标识一次导航实例，ViewInstance 负责实例状态。页面操作使用一套异步入口、状态、结果和清理规则。
- 提供异步打开、BeginOpen 在途请求控制、异步关闭、ForceClose、返回、完成结果、Replace、参数更新、换绑、BringToFront、按层或全部关闭、状态查询、等待实际清理，以及预加载和清除。可能等待页面、守卫或资源的操作返回可等待结果；即时状态查询和输入接纳保持同步。
- 打开和 Replace 在准备失败时保持旧页面可用；提交成功后，旧 ViewHandle 不能操作新实例。页面结果在关闭提交点确定，资源清理状态独立报告；取消结果等待不隐式关闭页面。
- Route 配置层级、覆盖方式、返回行为、历史、焦点、实例数量及溢出策略、停用实例缓存与过期策略、Tick 暂停策略。显示顺序、历史、焦点和输入资格分别计算。
- 实例额度按宿主与 Route 统计，在接纳请求的主线程步骤中原子预留；准备中的请求与未提交关闭的实例均占额度，缓存另计。默认满额返回忙碌，不再启动 Provider；单实例 Route 可显式选择返回已有的就绪实例，但不隐式更新参数、换绑或改变历史，已有实例仍在准备时返回忙碌。成功提交把预留转换为实例占用，失败或取消只释放本请求的预留，关闭提交释放该实例占用；迟到完成不得重复释放额度。取消后尚未结束的外部准备仍计入宿主在途上限，直至实际结束。
- Replace 原子预留目标 Route 额度；替换同 Route 实例时可借用被替换实例的额度，每个旧句柄同时只允许一个替换预留，跨 Route 则正常占用目标额度。新旧 View 可在准备期间短暂并存，仍受宿主在途及资源约束；提交时重新验证旧句柄、预留和守卫许可，失败只撤销候选，不能释放旧页额度。显式选择关闭旧实例腾出容量的溢出策略仍须通过守卫，不可把普通 Open 静默变成 ForceClose。
- 默认覆盖保留原 ViewInstance、绑定与激活作用域，不完成页面结果；数据通知和资源槽更新继续运行，业务 Tick 采用第 4 节生命周期表的可见性策略。InputGate 与焦点变化不控制 Tick。恢复覆盖不重新打开或再次执行首次激活钩子。
- 历史只记录声明参与历史的存活页面，按打开提交顺序维护。Back 先处理局部 Cancel，再按返回策略选择当前最上层合格页面，默认关闭该页；关闭后重新计算剩余页面的显示和输入资格，并按第 6 节恢复焦点，不强制将历史前驱置顶。普通关闭移除对应记录，关闭非顶层页面不重排其余记录；Replace 在原历史位置替换记录，BringToFront 只调整显示及输入仲裁。历史可供查询及项目显式导航，不隐式重排页面或重建已关闭页；重建通过新 Open 获得新句柄与结果。
- 共享依赖具有明确拥有者及释放条件；可选依赖降级和参数修改资格可查询。预加载和缓存具有版本、拥有者及淘汰规则。
- 共享依赖按显式声明的身份与内容版本复用，参数不兼容时拒绝本次获取，项目可声明独立变体；不得由后来的拥有者改写已有共享实例。预加载按资源身份与版本合并底层获取，各消费者分别持有请求资格或凭证；单个消费者取消不撤销其他消费者的获取。清除或版本失效使旧候选不能再发布，已有使用者的凭证保持有效至归还；新请求不得命中旧版本。
- 参数更新沿用准备与提交边界：异步准备不得修改当前参数、模型或控件，失败保留旧状态；提交前重新验证实例及代际，成功后使旧关闭许可失效。提交中用户回调的副作用不承诺回滚；异常时撤销相关输入并故障关闭，不能返回成功或保留半更新页面。
- 页面缓存只保留已解除绑定的 View 及明确移交的可复用资源，不保留上一导航实例的 ViewModel、Presenter、参数、命令、焦点或结果。关闭结束本次激活作用域；项目需要保留业务状态时通过外部服务或共享 ViewModel 再次传入。缓存命中仍创建新的 ViewInstance、ViewHandle、激活代际和结果；重置失败的 View 直接淘汰，不带病复用。
- 缓存接管前必须完成旧激活的解绑及会访问该 View 的在途工作清理，不合作操作仍持有它时不得入池复用。移交资源必须脱离旧作用域，由缓存唯一承担归还责任。关闭清理完成表示本次激活责任已清理或合法移交，不表示缓存资源已物理归还；缓存清除、淘汰与 Shutdown 的等待则包含相应凭证的实际归还。预加载不激活页面或接纳输入，页面缓存和预加载均设容量及失效策略。
- 导航操作结果与页面业务结果分离。操作使用统一状态：成功、取消、守卫拒绝、未找到、忙碌、代际失效、宿主已关闭及失败；前七类为可预期分支，失败携带异常及诊断标识。页面结果明确区分 Done(value)、普通关闭、Replace、强制关闭、宿主退出和故障关闭，不以默认业务值代替关闭原因。取消等待按异步取消契约结束本次等待，不改写被等待的共享结果。
- 异步打开按契约等待首次激活就绪；BeginOpen 可立即提供在途请求供调用方观察或取消。首次就绪、进入转场完成、可见、可输入和清理完成是独立状态。
- 关闭守卫决定是否离开页面。需要确认时调用项目提供的确认服务；拒绝或失效的许可保持页面与原结果，确认回调不得与导航队列自等待。确认页无法打开时保留原页：容量限制返回忙碌，加载异常返回失败并复用其诊断标识，不等待尚未接纳的确认请求。
- 同一页面与激活代际最多有一次在途关闭决议。普通 Back/Close 可合并观察；Done 与 Replace 仅重复观察同一请求标识时合并，不比较任意业务对象的深层值，不同请求在决议前返回忙碌。参数或绑定变更使旧许可失效，本次关闭返回代际失效，由调用方重新发起；拒绝后允许新请求重新确认。ForceClose、故障关闭和 Shutdown 可使在途确认失效，项目确认服务通过取消契约结束所属确认页，迟到许可不能再提交。

所有异步入口以下表作为完成点定义；操作取消与仅取消等待须在 API 上明确区分。合并关闭决议的观察者仅能取消自己的等待，不能撤销其他调用方正在观察的决议；撤销决议由其操作拥有者通过明确入口发起。关闭提交之后取消不能改变已确定的结果。批量关闭取消后停止接纳剩余目标，返回已提交、已拒绝与未尝试目标的逐项状态，已经提交的关闭继续退出与清理。

| 操作 | 默认等待到的完成点 |
| --- | --- |
| Open / Replace | 新页面首次就绪且提交成功；不等待进入转场或旧页清理 |
| BeginOpen | 同步返回请求对象；其完成任务与 Open 相同，取消入口作用于该请求 |
| Close / ForceClose / Done / Back | 关闭提交或明确的拒绝、忙碌等结果；不等待视觉退出及最终清理 |
| 等待转场 / 等待清理 | 分别观察视觉完成、该激活责任清理或合法移交；不改写业务结果 |
| 参数更新 / 换绑 / BringToFront | 对应状态提交成功或明确失败 |
| 预加载 / 清除缓存及预加载 | 分别等待预加载凭证就绪、目标凭证实际清理；清除以接纳时快照为范围，使相关在途预加载失效并等待迟到归还 |
| Shutdown | 本宿主退出清理终结；有失败则返回失败与未归还责任，仍在进行时不得报告成功 |
| 按层 / 全部关闭 | 对接纳时的目标快照按显示顺序从上到下逐项尝试，返回每项提交结果；拒绝或失败不阻止其他目标，不回滚已关闭页面，不追赶后来打开的页面 |

导航状态修改在主线程串行提交。外部准备和确认可交错完成，按完成后进入提交队列的顺序处理；提交前重新校验句柄、操作代际、目标状态及守卫许可，不保证不同页面按 Open 调用顺序激活。相同实例的冲突操作遵守以下规则：

| 阶段或竞争场景 | 行为 |
| --- | --- |
| 首次就绪前取消或关闭打开请求 | Open 以取消结束；尚未交付的视图在迟到后归还。首次就绪与 Open 成功在同一提交点确定，之后关闭不改写 Open 结果 |
| Replace 准备失败或提交前失效 | 保留旧页；提交时原子切换实例归属。旧页仍需确认时，只有许可有效才能提交 |
| Replace 提交后的进入转场失败 | 报告错误，将视觉状态恢复到可用终态并保留新页；终态恢复失败则故障关闭新页。必要准备和绑定须在旧页关闭前成功，新页失败不复活旧句柄 |
| Done、Back、Close 竞争 | 未提交时相同关闭意图合并，不同意图返回忙碌；首个通过资格和守卫检查的关闭提交确定唯一结果，提交后的请求观察同一次关闭，不能覆盖结果 |
| 已提交关闭、正在退出或清理 | 拒绝参数更新、换绑和 BringToFront；重复关闭不重复生命周期钩子或资源归还 |
| ForceClose | 绕过关闭守卫并跳过或终止视觉转场，取消相关在途准备；仍执行解绑和资源清理，不能强制终止不合作的外部任务 |
| 参数更新、换绑等待期间发生关闭或其他变更 | 完成后重新校验代际；失效候选只清理、不附着。换绑准备失败保留原绑定，提交后使旧绑定代际失效 |

关闭提交立即结束该激活的新工作准入并撤销输入；退出画面使用单独持有的视图与展示资源直到转场结束，再按缓存策略移交或归还。故障关闭与 Shutdown 不入缓存。关闭结果不等待视觉退出或最终清理；结果一经确定，后续清理或转场失败仅进入独立诊断，不改写原结果。

## 4. 生命周期、取消与资源持有权

- ViewInstance 统一驱动 View、绑定、Presenter 和激活 LifetimeScope。准备、提交、视觉退出、关闭清理与销毁各阶段有确定顺序；生命周期钩子按契约执行规定次数。
- LifetimeScope 负责作用域内的取消、操作跟踪、清理回调和资源持有权，供激活、绑定、资源槽与预加载使用。Cancel 立即结束新工作准入；DisposeAsync 等待实际清理，已可同步释放的对象可在此过程中立即归还。清理按依赖顺序执行，一项失败不阻止无依赖的其他项清理；依赖尚未解除的资源继续保留。重复 DisposeAsync 观察同一次清理及聚合错误，不自动重试。
- AcquiredView 包含 View 和一次归还责任，AcquiredResource<T> 包含资源对象和一次归还责任；取得的是使用权，不要求独占底层对象。Provider 交付 AcquiredView 前负责构造失败回滚；交付后由页面实例负责归还。释放异常不能被推断为完全未释放；适配器须说明部分完成及安全重试语义，仅明确支持幂等重试的责任允许显式重试，已确认归还的凭证不再归还。
- 清理诊断区分仍在进行、失败或归还状态不明、已确认完成，并保留相应拥有者和错误。重试更新同一责任记录；不得通过丢弃错误或重复 DisposeAsync 将未完成责任标记为成功。
- View 可在激活前配置异步资源加载器；常驻资源的加载操作可立即完成。子 View 可借用父 View 的活动加载器，借用只提供加载入口，不转移父级拥有权。每个已取得凭证必须在整个持有期内保持有效归还能力；若依赖加载器或适配器，其必要生命周期通过独立持有凭证延长到资源实际归还。无法延长时不得将资源移交到更长寿命的缓存，须在原拥有者退出前归还；在途加载和迟到结果也受此约束。缓存 View 再激活时清除旧活动上下文并注入当前加载器，不能沿用旧父级引用。WaitForResourceSources 可把首批资源键准备纳入首次就绪，后续更新由显示位置渐进处理。
- 取消与迟到完成按操作代际处理：失效结果不再附着，迟到取得的 AcquiredView 或 AcquiredResource<T> 仍须归还。正常关闭、重复关闭、打开失败、Replace 回滚、缓存淘汰与宿主退出均收敛到一致清理规则。
- 页面支持逐帧进入/退出转场、退出画面保留和退出时禁用输入；页面及子视图支持 Tick，覆盖或隐藏时按 Route 策略暂停、恢复。转场时长由页面配置。
- Navigator 使用一处有界导航队列串行处理状态变更与提交；Provider、生命周期准备、关闭确认、转场和最终清理的外部等待不占住队列执行权。等待后的提交重新校验代际与资格，生命周期回调不在队列执行权内等待嵌套导航。待处理请求与在途准备总量有配置上限，满载时新普通请求立即返回忙碌结果；已接纳请求保留完成提交资格，不因队列满而丢失完成通知。
- 生命周期钩子、守卫与清理回调不得等待依赖自身返回才能完成的操作，包括准备钩子等待本次 Open、清理回调等待所属 DisposeAsync、以及子操作反向等待父操作完成。框架只在受控 API 入口检查当前操作或作用域的直接自等待，明确报错并按所属阶段失败或继续其他清理；对已经取得的 Task 的等待、间接等待环及任意业务 Task 不承诺检测。嵌套导航仅允许无此依赖的等待，后续动作可在钩子返回后由调用方串联。
- 取消立即标记请求失效；ForceClose 与 Shutdown 的控制请求不受普通请求满载限制，重复请求合并，并在当前短提交结束后优先处理。外部操作采用合作式取消，仍占有资源的不合作操作持续出现在未完成清理诊断中。
- Shutdown 在主线程接纳时将宿主置为不可恢复的停止状态，立即拒绝新的打开、预加载、换绑及其他普通变更；取消所有在途准备，绕过关闭守卫，终止转场并清理活动页面、子视图、页面缓存及预加载。尚未完成的页面以宿主退出结束，已确定的结果保持不变；迟到资源继续归还，关闭期间不得再写入缓存。仅归还本宿主持有的凭证，不销毁项目共享服务或其他宿主的资源。重复调用观察同一次退出，查询、清理诊断及安全重试仍可用。
- 正常销毁 UIHost 前由项目显式等待 ShutdownAsync。调用方可取消等待，但不停止已启动的清理，也不将其标记为成功；后续等待可继续观察同一次清理。OnDestroy 只启动兜底清理并观察错误；独立于宿主组件生命周期的清理跟踪器继续持有未完成责任，直到确认归还或明确记录失败，不承诺进程退出后仍能执行清理。
- Unity 对象只在主线程创建、查询、布局和释放。宿主使用的 ViewModel、ObservableList 及其通知须在宿主主线程修改和发送；框架提供或生成的属性与集合在写入前检查，自定义 setter 由项目遵守契约，框架收到违规通知时报告并拒绝更新 UI，不能回滚已经发生的业务修改。后台服务通过公开主线程派发入口提交数据；框架处理外部异步完成后统一切回主线程再提交状态，Core 通过注入执行上下文保持不依赖 Unity。
- UI 转场与平滑滚动默认使用非缩放时间，业务 Tick 的时间源独立配置，默认同样使用非缩放时间；游戏暂停不停止输入、布局或清理驱动。暂停业务 Tick 的默认条件见下表，不由 InputGate 推导。
- UIHost 默认随所属场景销毁，跨场景持久宿主由项目显式配置；场景切换前按 Shutdown 契约等待清理，框架不接管场景加载。持久宿主持有的 View 必须放在兼容的持久层级，不能缓存属于待卸载场景的对象。活动 View 被外部销毁时立即使绑定与输入身份失效、故障关闭并清理其余凭证；缓存 View 被销毁则淘汰。不可再访问已销毁对象，Provider 的归还适配须容忍视图已销毁，并且仍只执行一次凭证归还。

以下表格统一默认生命周期行为。页面覆盖、子视图显式停用和页面关闭是不同操作；业务 Tick 不包括框架的转场、布局与清理驱动。

| 阶段 | 绑定与数据更新 | 业务输入 / Tick | 拥有者与完成条件 |
| --- | --- | --- | --- |
| 准备 | 候选独立准备；提交前完成必要绑定，不改动旧页 | 无 / 无 | 请求持有候选，失败后清理；未产生成功的激活 |
| 进入转场 | 保持绑定，接收更新 | 默认转场结束才可输入 / 默认暂停 | ViewInstance 与激活作用域持有；首次就绪与转场完成分别报告 |
| 激活 | 保持绑定，接收更新 | 按资格接纳 / 执行 | 当前激活持有资源；初次激活钩子每个激活代际一次 |
| 覆盖或隐藏 | 保持绑定，继续数据和资源更新 | 按覆盖及门控资格接纳 / 默认仅完全隐藏时暂停，可按 Route 调整 | 同一实例与作用域持续有效，恢复不重跑首次激活；门控关闭不暂停 Tick |
| 子视图显式停用 | 解除绑定，不更新控件 | 无 / 无 | 结束子激活作用域；子视图容器可保留 View、参数及明确拥有的模型用于恢复，不转移到页面缓存；实际停用等待旧激活清理 |
| 关闭提交后与视觉退出 | 立即使绑定代际失效，解除订阅，不接收业务更新；保留最终画面 | 无 / 无 | 页面结果已确定；退出持有者保留展示所需凭证，框架继续驱动转场和清理 |
| 缓存 | 无绑定，无活动模型或上下文 | 无 / 无 | 缓存独占可复用 View 与移交凭证；重新打开创建新实例和新激活 |
| 清理与归还 | 无绑定 | 无 / 无 | 清理跟踪器保留未完成责任；仅全部归还或合法移交后报告相应清理完成 |

子视图再激活创建新的激活作用域并重新绑定，执行该代际的一次激活钩子；不能在旧在途工作仍可能访问 View 时复用它。关闭提交结束业务更新不代表立即释放展示对象，解除绑定时不得清空退出转场仍在使用的画面资源。父级关闭同时终止活动和已停用的子视图，并清理容器持有的对象。

## 5. 子视图、普通列表与虚拟列表

- 子视图支持异步准备、父子激活、动态替换、停用与再激活、原实例换绑、参数更新、内容版本、局部关闭请求及 Tick，并沿父级取消和清理边界运行；本地准备可立即完成。
- 普通列表可将条目 View 模板绑定到多份数据；条目删除、替换或复用前解除旧绑定和输入。RecyclingListElement 支持物化全部条目的较小数据集。
- 提供轻量固定槽位容器，支持绑定 Prefab 中已有的子 View，或将模板实例放入显式挂点；复用子视图生命周期，不引入第二套导航或虚拟化。容量由槽位确定，空槽停用并解绑，超量数据按配置拒绝或截断并报告，不静默扩容；绑定已有节点只借用对象，动态实例由容器持有。槽位之间或与父 View 不能重复拥有内部 Element。
- 虚拟列表以布局、物化复用、定位和交互连续性为框架职责。以下能力均属于本次必须实现及验收的核心目标；默认使用固定尺寸和单模板，复杂能力按需配置，不能仅以扩展接口代替实现。
- 支持纵向、横向单列列表，以及纵向滚动的规则 Grid。列表支持固定尺寸、业务显式提供逐项尺寸、按布局测量的动态尺寸；Grid 使用统一单元格尺寸，支持显式列数或按可用宽度计算列数。支持间距、内边距、视口尺寸变化后的范围重算；暂不提供瀑布流、跨行跨列和自由二维布局。
- 动态尺寸使用估算值定位未物化条目，只测量已物化条目；按稳定键、内容版本、模板和布局约束缓存测量结果。文字、图片或容器尺寸变化可使尺寸缓存失效并重新布局，不为取得精确尺寸而物化全部数据；测量与布局按帧合并并限制工作量。
- 虚拟列表独占 Content 尺寸和条目根节点的排布，条目内部可使用原生布局组件；检测并报告在相同受控属性上运行的 LayoutGroup、ContentSizeFitter 等冲突。固定尺寸、估算尺寸、滚动轴占用尺寸和 Grid 列数必须有效且大于零；配置不合法时拒绝启用，运行期测得无效尺寸则保留最后有效值或估算值并报告错误，不进入无限测量或物化循环。
- 按视口及配置的预留行物化、回收和复用条目；支持 ObservableList 的增删改移、批次和重置，以及单项内容刷新。支持模板选择器和按模板隔离的复用池，模板变更按替换处理；池总容量有上限，数据总量增加不导致全部条目实例化。保留异步条目准备与本地立即完成路径，快速滚动时限制在途准备数量；旧准备完成不得覆盖条目当前数据。
- 条目准备或绑定失败只使该条目进入失败状态：清理半成品、保留有效占位尺寸、报告错误并提供按稳定键重试入口及可配置失败展示。失败条目不接受输入，不逐帧自动重试；重试受当前来源版本和并发上限约束。定位或焦点请求遇到目标准备失败时明确失败，不能无限等待；配置级错误则停止整个列表并诊断。
- 提供按索引或稳定键定位、使条目进入可视区，以及起始、居中、末尾对齐；支持立即定位与平滑滚动。索引在请求时解析为稳定键，后续增删改移仍跟踪同一条目；不存在的目标返回未找到，空列表安全返回。动态尺寸先按估算定位，再在目标物化测量后修正，定位完成表示当前布局下已达到可实现的目标对齐。边界位置钳制到合法滚动范围；新的定位、用户拖动、换源、重置或关闭取消旧的平滑滚动，定位期间目标被删除则结束并报告未找到。
- 定位在目标准备完成、首次有效布局修正达到对齐后结束，不等待图片等后续资源全部稳定；后续尺寸变化按阅读锚点规则处理，不重新打开已完成的定位。布局持续失效时，达到配置的修正次数上限后返回未收敛失败并保留当前位置。本地准备和绑定不人为增加等待帧，依赖布局测量的最终位置允许在布局完成后修正。
- 增量更新、尺寸修正和视口变化默认以首个可见条目的稳定键及条目内偏移保持阅读位置；锚点被删除时优先使用原顺序的后继，其次前驱，空列表回到起点。提供滚动位置的捕获与恢复，以及可选的末尾跟随：仅在更新前已处于末尾容差内时继续跟随，否则保留阅读位置。显式定位期间以定位目标为准，拖动期间补偿不造成指针跳变。换源和重置默认回到起点，恢复旧位置必须由业务显式请求。
- 条目点击和选中状态沿用绑定与 ViewModel；框架以来源代际、条目稳定键及条目内控件标识保存逻辑焦点，提供键盘/手柄方向导航和目标自动滚入视口，Grid 按行列寻找相邻目标。条目回收时解除原生控件焦点，异步物化后只在焦点请求仍有效时恢复；目标控件失效时回退到该条目的默认可交互控件，再按页面焦点规则回退。不让 EventSystem 的焦点随复用对象跳到另一条数据。多选、范围选择和业务选择限制由项目处理。
- 提供可见范围、距首尾边界和滚动状态的查询及变化通知，供项目接入加载更多、置顶按钮等功能。框架不内置游标分页来源 PagedList、双向分页窗口、查询重试、分组/树形数据模型或展开折叠逻辑；项目负责加载与组织数据，再更新 ObservableList。分组标题和树节点可作为扁平条目使用模板选择器展示；加载提示与重试由普通页面处理。
- 滚动位置快照包含来源身份、锚点稳定键和条目内偏移，不能只保存索引或像素偏移。默认只恢复同一来源；跨来源恢复要求项目明确声明键空间兼容。锚点仍在时按当前布局重新计算位置并钳制；目标已删除时使用仍有效的后继、其次前驱，无可用锚点则回到起点并报告回退。方向、列数或视口变化不复用旧绝对坐标；位置快照不持有条目 View、模型或资源凭证。
- 换源、数据增量、条目复用及父页面关闭按版本和所有权规则处理，不把旧数据、输入、订阅或资源带入新条目。

## 6. uGUI 输入与布局

- 可交互 Element 的原生事件、值与交互属性接入绑定和命令。InputGate 管理页面级阻挡令牌；覆盖、模态、焦点、键盘/手柄选择及控件可交互状态遵守页面输入资格。
- 页面在首次获得输入资格时应用声明的默认焦点；关闭页面或模态退出屏障解除后，重新选择最上层合格页面，再恢复该页保存的逻辑焦点。仅当原页面仍是该目标时恢复其旧焦点，不能因历史记录或旧模态快照抢走其他前台页面的焦点。目标控件已删除、隐藏或禁用时，依次回退到页面默认控件、登记顺序中的首个有效控件，均不存在则清空焦点。模态期间焦点导航限制在获得输入资格的页面范围内，不跳入下层。
- 点击、按下/抬起、拖拽、滚轮、提交和方向导航统一检查输入资格，自定义 Element 沿用同一入口。输入门控关闭、页面遮挡或关闭导致当前手势失效时，取消其捕获并执行一次内部结束清理，不派发业务点击、提交或 Drop；剩余手势消费到结束，不能转交下层或复用后的对象。停止惯性、清理拖拽等内部工作不受业务输入门控阻断。
- UIHost.RequestBack 和 UIBackInput 接入返回输入。局部 Cancel 处理优先；同一 EventSystem 的同帧请求只接纳一次。返回请求是否接纳与页面最终关闭结果分别报告。
- 同一 EventSystem 的宿主登记明确且无歧义的输入优先级。最高优先级且持有模态屏障的宿主独占该 EventSystem 的页面输入，屏障包括进入和退出转场期间；由宿主再按页面资格分发或消费。没有模态屏障时，返回及键盘/手柄输入交给焦点所属宿主，无焦点则交给最高优先级的可输入宿主。返回被选定宿主接纳后，即使守卫拒绝也不向其他宿主重发；无模态屏障时 Pointer 按实际命中宿主分发。独立 EventSystem 分别仲裁。
- UIHost 的显示排序与模态输入优先级使用统一登记顺序，动态 BringToFront 同时更新排序与仲裁。项目自行修改 Canvas 排序造成冲突时明确诊断并拒绝有歧义的输入配置；自定义相机或宿主排序须通过公开适配提供一致的显示与命中顺序。
- 模态屏障独立于页面输入资格，从模态显示提交开始持续到视觉退出完成；关闭提交后页面自身不可输入，屏障仍消费新的 Pointer、滚轮、提交、方向和返回输入，不落到下层，也不重复发起关闭。没有退出动画或被 ForceClose 终止动画时，确认退出画面已移除即可解除屏障。退出转场异常须移除画面并释放屏障；更上层新模态仍按排序获得输入，多个屏障分别持有，不能因一个退出而释放其他屏障。Shutdown 清理屏障且不恢复已停止宿主的焦点。
- 模态页的关闭 Pointer 持续被屏障消费至手势结束，不穿透下层。基础适配支持 EventSystem/StandaloneInputModule；安装 Input System 的工程启用独立编译的输入适配；项目输入模块可登记同一手势状态读取器。
- 提供安全区适配、项目传入的软键盘区域覆盖、受控即时布局刷新，以及滚动、滚动条和遮罩适配。项目按键或输入动作通过公开入口接入。
- 缩放沿用原生 CanvasScaler，不增加第二套分辨率缩放系统。屏幕 UI 支持 Screen Space Overlay 与 Screen Space Camera；相机模式要求明确的渲染与事件相机。安全区及项目提供的键盘区域以屏幕像素输入，转换到目标 RectTransform 局部坐标；列表尺寸、间距、偏移与定位误差均使用该 Content 的局部 Canvas 单位。分辨率、方向或缩放变化触发布局与锚点更新，不重复应用缩放。World Space Canvas 的空间遮挡、距离缩放及屏幕安全区映射不属于本次保证范围，接入须由项目适配。

## 7. 诊断、Editor 与交付

- UIErrors.Sink 接收项目错误处理，Reported 供额外观察；活动 UIHost 在没有项目错误出口时回退 Unity Console。常规操作不产生大量信息日志。
- 可预期的取消、拒绝、未找到、忙碌、失效和宿主关闭通过操作结果返回，不写异常日志；Provider、生命周期、绑定提交及清理异常携带宿主、页面句柄、操作、阶段和唯一诊断标识。每次异常发生只向错误出口报告一次，逐层传播、等待者和快照复用该标识；后续重试产生的新异常单独记录。生命周期或诊断观察者抛错须隔离，不能中断状态提交与清理。
- Navigator 发布类型化生命周期事件，并提供按需开启的有界追踪、活动实例、依赖、拥有者、历史、预加载、缓存和未完成清理快照。View 提供输入门控与首帧资源准备快照，uGUI 提供射线命中诊断；读取诊断不改变业务状态。
- Editor 提供绑定 Manifest 与源码定位、目标 Element 定位、View/UIHost Inspector 诊断、Prefab 与 Route 结构校验，以及项目登记 UI 目录的构建前校验。
- 提供全屏页、模态弹窗和非交互提示三类策略预设及轻量页面向导，创建必要 View Prefab 结构和可编辑的 ViewModel/Route 声明；预设只展开为已有层级、覆盖、历史、输入与缓存策略，不新增运行时页面类型。非交互提示默认不抢焦点、不阻挡输入、不接纳返回；生成文件不覆盖已有业务代码，默认不要求 Presenter，不引入 Mixed/IL 后处理第二套属性生成流程。
- 手动校验、Binding Inspector、Prefab 导入/保存后的增量检查及构建前检查复用同一套规则，覆盖项目登记的 UI 目录及明确引用的资产。增量检查按受影响资产合并调度；编译或导入忙碌时排队并在结束后补跑，避免漏检及递归导入。构建前以当前完整声明与资产重新校验，错误阻断构建，警告单独报告；新增公共控件兼容匹配与容器拥有边界检查。
- 交付符合 Unity Package Manager 布局的包：根目录包含 `package.json`、`README.md`、`CHANGELOG.md`、`LICENSE.md` 和 `Documentation~/`；`Runtime/` 与 `Editor/` 使用各自的程序集定义及有效 `.meta` 文件，生成器 Analyzer 放在包内 `Analyzers/`。清单准确声明包名、版本、Unity 版本和必需依赖；TMP 与 Input System 只在项目安装对应依赖时启用。
- 示例分别放在 `Samples~/` 下，并在 `package.json` 的 `samples` 数组中登记名称、说明和路径。包安装后不自动导入示例，Runtime 和 Editor 不引用示例程序集或资产；用户可在 Package Manager 中逐项选择 Import。
- 提供基础页面、设置与控件、导航与虚拟列表、资源后端接入示例。每项包含可运行场景或明确的接入入口，使用公开 API；若依赖另一示例，在清单说明和示例文档中写明导入顺序。
- 提供自定义控件接入与常用组合的公开 API 示例，覆盖确认对话框、Toast 和 Loading，以及项目服务驱动的语言/主题切换与转场适配。框架不内置翻译库、主题编辑器或绑定特定动画库；示例须证明切换后文字、资源、动态尺寸和输入资格正确刷新。

- 列表性能：分别记录固定尺寸与动态尺寸、多模板场景预热后滚动的框架 CPU 耗时 P95/P99、每帧 GC 分配及每帧测量次数，区分业务绑定和资源加载开销；具体预算在目标设备验收前确定并登记，不用总数据量线性增长的物化开销替代虚拟化。
- 接入成本：Basic Sample 明确列出手写 ViewModel、View/Prefab、Route 声明和宿主配置，标注生成产物；普通页面不要求编写 Presenter 或手动维护生成绑定订阅。
- 绑定：验证双向初始化无回写循环、输入提交时机、转换失败、嵌套模型替换及 null 回退；换绑准备失败保持旧 UI，提交异常撤销输入并完成故障清理。自定义控件不修改框架源码即可接入；框架属性/集合的后台写入在修改前被拒绝，自定义模型违规通知不更新 UI，通过主线程入口更新成功。
- 缓存与退出：缓存命中产生新句柄、新结果且没有旧订阅；旧在途工作未结束时不复用 View。等待关闭后资源允许由缓存持有，等待清空缓存后相应凭证全部归还。Shutdown 拒绝新工作、跳过守卫和转场、清空宿主拥有的缓存及预加载；迟到完成不重新附着或入池，项目共享服务仍可用。
- 焦点与手势：弹窗关闭恢复原控件，控件失效按规则回退；模态不能导航到下层。拖拽中关门、遮挡或关闭只清理一次且不触发下层点击或 Drop；虚拟条目包含多个控件时恢复到同一逻辑控件，异步恢复不得抢走用户新焦点。
- 列表异常：条目加载或绑定失败保留占位并可显式重试，不阻塞其他条目；无效尺寸与布局冲突可定位，持续布局变化按修正上限结束定位。定位后图片改变尺寸走锚点规则，不重启定位；失败或取消的焦点请求不遗留原生选择。
- 结果与扩展：守卫拒绝和忙碌不产出异常日志；同一次 Provider 或清理异常经多个等待者观察仍只报告一次。观察者抛错不破坏提交和释放。常用组合及语言/主题适配示例通过公开 API 完成更新，动态列表尺寸与输入资格同步生效。
- 并发与守卫：并发打开单实例 Route 只接纳一个准备，其他请求按声明返回已有就绪实例或忙碌；取消及迟到完成不重复释放额度，同 Route Replace 无需额外实例额度但不能并行替换同一旧句柄。重复关闭只产生一次同意图确认，不同意图返回忙碌；变更代际、ForceClose 或 Shutdown 后旧许可不能提交。受控 API 的直接自等待明确失败，不依赖超时判定成功。
- 历史与生命周期：A 被 B 完全隐藏后保留原句柄、绑定及数据更新，默认暂停 Tick；返回恢复 A 不重跑首次激活。A/B/C 依次打开、B 提到前台后关闭 B，剩余 C 获得前台资格，不因 B 的历史前驱是 A 而置顶 A。BringToFront 不改写历史，已关闭页不自动重建。子视图停用解除绑定、再激活创建新作用域；父关闭清理活动及停用子视图。
- 模态退出：有退出动画时，关闭提交后的新点击、滚轮、键盘提交和返回均不能到达下层；视觉退出完成后再恢复焦点和输入。覆盖零时长、ForceClose、转场失败与叠加模态；原关闭 Pointer 即使晚于视觉退出结束也不得穿透。
- 加载器寿命：借用父加载器取得的资源，在父级停止后仍能按凭证安全归还；依赖无法延长时不进入长期缓存。缓存再激活只使用当前注入的加载器；在途加载迟到完成、缓存淘汰和 Shutdown 均不访问已失效的归还后端。
- 完成点与环境：按第 3 节操作表验证 Close 返回与退出/清理完成分离，批量关闭中一页拒绝不影响其他页且结果逐项可查。关闭 InputGate 后可见页面 Tick 继续；timeScale 为零时转场与平滑滚动仍完成。场景宿主退出、持久宿主跨场景及 View 被外部销毁均无失效输入、重复归还或无主凭证。
- Provider：同一导航路径分别接入本地立即完成和延迟加载适配器，验证状态提交、异常、取消及迟到归还一致；无其他等待条件时本地路径不人为增加等待帧。多调用方观察同一打开/清理结果不重复消费底层获取操作；记录高频获取分配，再决定是否使用 ValueTask，不以声明 Async 推断一定切线程或延迟。
- 控件与编辑接入：通过向导分别创建三类页面并使用公开 API 运行；同一公共文本、输入及下拉绑定可在 Legacy/TMP 适配间切换。自定义 Element 初始化失败仍清理监听，父子容器不重复初始化或释放。固定槽位覆盖空槽、溢出、换绑与父关闭，借用节点不被误销毁；Prefab 增量检查在编译结束后补跑，构建检查不依赖旧缓存结果。
- 资源槽：A 已显示时请求 B 失败仍显示 A，同时可查询 B 的失败状态；连续换键、清空或直接赋值后的迟到资源均归还。B 成功显示但 A 归还失败时保留 B 与 A 的清理记录；赋值故障不留下引用已释放资源的控件。

- 契约边界：参数更新准备失败保留旧状态、提交异常故障关闭；合并关闭的一个观察者取消不影响其他观察者；批量取消逐项区分已处理与未尝试。共享预加载的单个消费者取消不影响其余消费者，旧版本迟到资源不被新请求接管。位置快照跨来源默认拒绝，显式兼容恢复及锚点删除有明确回退；Overlay 与 Camera 模式下改变分辨率及 CanvasScaler 后，安全区与列表定位仍使用一致坐标。
