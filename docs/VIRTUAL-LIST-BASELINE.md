## 指标口径

ProfilerRecorder 以 SumAllSamplesInFrame 合并同一标记的帧内调用，下一帧读取 LastValue，与 MeasurementSnapshot.Frame 对齐。CPU 使用 `MUI.VirtualList.Maintenance` 的同步区间并集，扣除相同帧内临时业务 RowBinding 的独立标记，然后对所得逐帧值计算 P95/P99；采用向上取整的 nearest-rank，不把两个独立分位数相减。

Maintenance 覆盖 LateUpdate 与刷新迭代器同步片段，包含其中触发的子视图准备、绑定基础设施和原生尺寸重建。仅扣除临时业务绑定内写入 LayoutElement 高度、Image 颜色和模板名称检查的耗时。后端资源加载次数为零，不能据此估计资源加载性能。原生 Canvas 后续布局/渲染和异步完成回调不由这个 CPU 指标完整覆盖；各子阶段属于包含关系，不能相加作为总耗时。

GC 为 Unity `GC Allocated In Frame` 的整帧值，包含框架、Unity、渲染和观察脚本，未单独测量框架分配；表内以 KiB（1024 字节）表示。RSS 由宿主每 250ms 只读采集整个 Player 进程；日志刷新时机未能关联各组窗口，因此只保留整次运行峰值，不用它判断逐组内存变化或泄漏。
